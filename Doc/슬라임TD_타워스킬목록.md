# 슬라임TD — 타워 스킬 목록 (등급별 큰 분류)

[타워 스킬 레퍼런스 조사](슬라임TD_타워스킬_레퍼런스조사.md)를 바탕으로, 현재 프로젝트 구조(4등급 / 2개 합성 / 계열 없음 / 세로 한 손 조작)에 맞는 스킬을 **등급별로 넓게** 분류한 목록이다.

- 개별 타워 단위 설계는 하지 않는다. 각 분류는 **타워 후보를 만들 때 고르는 풀**이다
- 세분화(수치, 타워별 배정, 발동 조건)는 로스터 확정 단계에서 진행한다
- 합성 결과가 무작위라 **한 등급 안에 역할(딜러/광역/제어/지원/경제)이 고르게 섞이도록** 풀을 구성한다

---

## 등급별 스킬 슬롯

| 등급 | 스킬 슬롯 | 발동 방식 |
|---|---|---|
| 일반 | 없음 (기본 공격만, 단타/단일 대상) | — |
| 희귀 | 특수 메커니즘 패시브 1개 | 패시브 (공격에 묻어남) |
| 영웅 | 패시브 + 자동 발동 스킬 1개 | 쿨타임 또는 확률 |
| 전설 | 패시브 + 자동 발동 스킬 + 필드급 효과 | 자동 (액티브는 추후 검토) |

---

## 일반 — 기본 공격 유형

스킬 없이 공격 방식만 다르다. 이후 등급의 스킬이 얹힐 기반이다.

| 유형 | 설명 |
|---|---|
| 단일 원거리 | 표준 연사 / 표준 데미지 |
| 관통 | 일직선 관통, 느린 연사 / 높은 데미지 |
| 근접 | 표준 연사 / 표준 데미지 |
| 근접 중량 | 느린 연사 / 높은 데미지 |

## 희귀 — 패시브 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 연사 변형 | N타마다 다중 발사 (버스트) | 레인저 |
| 크리티컬 | 확률로 치명타 | 기사 |
| 관통 강화 | 관통 수 증가, 관통할수록 피해 증가 | BTD6 석궁 |
| 단순 제어 | 타격 시 기절 / 이감 / 방감 | 운빨 충격로봇·악마병사 |
| 경제 | 처치 시 확률로 골드 | 협타디 고블린 폭주족, 운빨 산적 |

## 영웅 — 패시브 + 자동 스킬 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 광역 사격 | 부채꼴 / 다중 대상 동시 사격 | BTD6 택 슈터 |
| 넉백 | 타격 시 슬라임을 뒤로 밀어냄 | BTD6 하강풍, 운빨 캡틴 로카 |
| 범위 폭발 | 착탄 지점 범위 피해 | BTD6 폭탄 슈터 |
| 상태이상 연계 | 디버프 걸린 슬라임에 추가 피해 | BTD6 아이스 취약화 |
| 인접 버프 | 주변 타워 공속 / 공격력 증가 | BTD6 빌리지, 운빨 독수리장군 |
| 처치 누적 성장 | 처치 시 공격력 영구 증가 | 운빨 블롭, 협타디 우주병사 |
| 경제 강화 | 골드 보너스, 소환 보조 | 협타디 코인맨 |

## 전설 — 필드급 효과 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 보스 딜러 | 최대 체력 비례 피해 | 협타디 검귀, 운빨 랜슬롯 |
| 광역 제어 | 경로 영구 장판 (이감 / 가시) | 협타디 빙결기사, BTD6 스파이크 공장 |
| 전역 버프 | 필드 전체 타워 공격력 / 공속 증가 | 협타디 고대 청룡·부두술사 |
| 전역 공격 | 사거리 무관 필드 전체 타격 | 협타디 클라라 |
| 분열 특화 | 분열 전 본체 특화 / 분열 후 잔챙이 청소 특화 | BTD6 MOAB 특화 vs 광역 |
| 위기 역전 | 라이프 손실 시 자동 발동 | BTD6 폭탄 폭풍 |
| 랜덤 / 도박 | 확률 진화, 랜덤 보상 (1~2종 한정) | 협타디 미믹, 운빨 개구리 왕자 |

---

## 공통 분류 (등급 무관)

등급이 올라도 이어서 쓰이는 효과 축이다.

| 축 | 하위 효과 |
|---|---|
| 피해 | 단일 / 관통 / 범위 / 비례(최대 체력) |
| 제어 | 이감 / 기절 / 넉백 / 장판 |
| 약화 | 방감 / 취약화 / 지속 피해 |
| 버프 | 인접 / 전역, 공속 / 공격력 |
| 경제 | 처치 골드 / 소환 보조 |
| 성장 | 처치 누적 / 시간 누적 |
| 특수 | 분열 연계 / 위기 발동 / 확률 진화 |

## 우선 도입 제안

슬라임 소재와 가장 잘 맞고 구현 비용이 낮은 순서.

1. **넉백** — 슬라임이 물컹하게 튕겨나가는 손맛 연출과 직결
2. **크리티컬 / 버스트** — 이미 희귀 2종으로 확정, 공격 파이프라인만 있으면 된다
3. **이감 / 기절** — 상태이상 표현은 얼굴 표정 시스템과 연결
4. **처치 시 골드** — 랜덤 소환 기회를 늘려 루프 강화
5. **분열 특화** — 분열 메커니즘 구현 후 도입

## 결정 필요 (세분화 전)

- 기본 발동 방식: 쿨타임 / 확률 / 마나
- 액티브 스킬(플레이어 조작) 도입 여부 — 세로 한 손 조작이라 자동 발동이 기본
- 버프 / 디버프 중첩 규칙과 상한
- 슬라임 속성 상성 도입 시기
