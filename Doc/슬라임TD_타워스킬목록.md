# 슬라임TD — 타워 스킬 목록

[타워 스킬 레퍼런스 조사](슬라임TD_타워스킬_레퍼런스조사.md)를 바탕으로, 현재 프로젝트 구조(4등급 / 2개 합성 / 계열 없음 / 세로 한 손 조작)에 맞는 스킬을 **넓게** 분류한 목록이다.

- 개별 타워 단위 설계(수치, 타워별 배정)는 로스터 확정 단계에서 진행한다
- 합성 결과가 무작위라 **한 등급 안에 역할(딜러/광역/제어/지원/경제)이 고르게 섞이도록** 구성한다

---

## 용어

| 용어 | 의미 |
|---|---|
| **타워 레벨** | 로비에서 올리는 **영구 성장**. 타워 종류별로 쌓이며 합성과 무관하다 |
| **타워 강화** | **전투 중 성장**. 전투가 끝나면 초기화된다. 도입 여부와 방식은 추후 결정 |
| 패시브 스킬 | 타워에 꽂는 상시 효과. 공용 정의를 어떤 타워에도 꽂을 수 있다 |

## 구조 원칙

- 스킬은 **공용 정의**로 두고 어떤 타워에도 꽂을 수 있다
- **수치는 타워별로 다르다.** 스킬을 꽂을 때 기본값과 타워 레벨당 증가폭을 타워가 따로 가진다
  - 예: 일반 타워 공격력 +5 (+0.1/레벨), 희귀 타워 공격력 +10 (+0.2/레벨)
  - 값 = `기본값 + 증가폭 × (타워 레벨 - 1)`
- 수치는 **고정값**이며 등급에 귀속되지 않는다. 일반은 약하게, 희귀는 높게 주는 것은 타워별 설계 결과다
- 패시브는 **여러 개** 꽂을 수 있다. 등급별 개수는 타워를 조립하면서 정한다 (예: 일반은 1개, 희귀는 1개 또는 특수형)
- 스킬 하나가 수치를 여러 개 가질 수 있다 (예: 처치 시 골드 = 확률 + 보상액)
- **기본 공격은 "한 발 발사"만 담당한다.** 관통, 이중 화살, 크리티컬 등은 전부 스킬로 분리한다

## 공용 패시브 풀

### 능력치형

| 스킬 | 효과 |
|---|---|
| 공격력 강화 | 공격력 +N |
| 공격속도 강화 | 공격속도 +N |
| 크리티컬 확률 | 치명타 확률 +N |
| 크리티컬 피해 | 치명타 배율 +N |
| 사거리 강화 | 사거리 +N |

### 특수형

| 스킬 | 효과 |
|---|---|
| 관통 | 일직선 관통 |
| 이중 화살 | 확률로 화살 두 발 발사 |
| 처치 시 골드 | 처치 시 확률로 골드 획득 (보상액 +10 등) |

## 등급별 스킬 가이드

| 등급 | 기본 구성 |
|---|---|
| 일반 | 공용 패시브 약하게 1개 |
| 희귀 | 패시브 1개 또는 특수형 스킬 |
| 영웅 | 패시브 + 자동 발동 스킬 1개 (쿨타임 또는 확률) |
| 전설 | 패시브 + 자동 발동 스킬 + 필드급 효과 |

실제 슬롯 수는 타워 조립에 따라 달라질 수 있다.

## 희귀 — 특수형 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 연사 변형 | N타마다 다중 발사 | 레인저 |
| 크리티컬 발동 | 확률로 치명타 공격 발동 | 기사 |
| 관통 강화 | 관통 수 증가, 관통할수록 피해 증가 | BTD6 석궁 |
| 단순 제어 | 타격 시 기절 / 이감 / 방감 | 운빨 충격로봇·악마병사 |

## 영웅 — 패시브 + 자동 스킬 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 광역 사격 | 부채꼴 / 다중 대상 사격 | BTD6 택 슈터 |
| 넉백 | 타격 시 슬라임을 뒤로 밀어냄 | BTD6 하강풍, 운빨 캡틴 로카 |
| 범위 폭발 | 착탄 지점 범위 피해 | BTD6 폭탄 슈터 |
| 상태이상 연계 | 디버프 걸린 슬라임에 추가 피해 | BTD6 아이스 취약화 |
| 인접 버프 | 주변 타워 공속 / 공격력 증가 | BTD6 빌리지, 운빨 독수리장군 |
| 처치 누적 성장 | 처치 시 공격력 증가 (전투 중) | 운빨 블롭, 협타디 우주병사 |
| 경제 강화 | 골드 보너스, 소환 보조 | 협타디 코인맨 |

## 전설 — 필드급 효과 풀

| 분류 | 효과 | 레퍼런스 |
|---|---|---|
| 보스 딜러 | 최대 체력 비례 피해 | 협타디 검귀, 운빨 랜슬롯 |
| 광역 제어 | 경로 영구 장판 (이감 / 가시) | 협타디 빙결기사, BTD6 스파이크 공장 |
| 전역 버프 | 필드 전체 타워 공격력 / 공속 증가 | 협타디 고대 청룡·부두술사 |
| 전역 공격 | 사거리 무관 필드 전체 타격 | 협타디 클라라 |
| 분열 특화 | 분열 전 본체 특화 / 분열 후 잔챙이 청소 특화 | BTD6 MOAB 특화 vs 광역 |
| 위기 역전 | 라이프 손실 시 자동 발동 | BTD6 폭탄 폭풍 |
| 랜덤 / 도박 | 확률 진화, 랜덤 보상 (1~2종 한정) | 협타디 미믹, 운빨 개구리 왕자 |

## 추후 후보 (공용 패시브 풀 확장)

| 분류 | 효과 |
|---|---|
| 조건부 수치 | 첫 타 강화, 같은 대상 연속 공격 누적, 체력 낮은/높은 슬라임 추가 피해 |
| 슬라임 소재 | 미세 넉백, 미세 이감, 분열 직후 / 본체 / 잔챙이 추가 피해 |
| 성장 | 처치 수 비례 공격력, 라운드가 길어질수록 공격속도 (타워 강화와 함께 검토) |

## 우선 도입 제안

1. **넉백** — 슬라임이 물컹하게 튕겨나가는 손맛 연출과 직결
2. **크리티컬 / 연사 변형** — 희귀 2종으로 이미 확정
3. **이감 / 기절** — 상태이상 표현을 얼굴 표정 시스템과 연결
4. **처치 시 골드** — 랜덤 소환 기회를 늘려 루프 강화
5. **분열 특화** — 분열 메커니즘 구현 후 도입

## 결정 필요

- 기본 발동 방식: 쿨타임 / 확률 / 마나
- 액티브 스킬(플레이어 조작) 도입 여부 — 세로 한 손 조작이라 자동 발동이 기본
- 버프 / 디버프 중첩 규칙과 상한
- 타워 강화(전투 중 성장) 도입 여부와 방식
- 타워 레벨의 최대치, 레벨업 비용, 재화
- 슬라임 속성 상성 도입 시기
