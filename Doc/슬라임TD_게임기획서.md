## 2. 핵심 컨셉

Bloons TD의 재미는 아래 두 축에서 나온다.
1. **경로를 따라 몰려오는 적을 다양한 타워 조합으로 처치하는 전략성**
2. **풍선이 레이어별로 터지며 작아지는 시각적 카타르시스 + 속성 상성**

슬라임 TD는 이 구조를 그대로 가져오되, **"터지는 풍선" 대신 "쪼개지는 슬라임"**이라는 소재 특성을 살린다.

- 슬라임은 풍선처럼 한 방에 사라지지 않고, **때릴 때마다 물컹하게 튕기며 반응**하다가 일정 데미지가 쌓이면 **더 작은 슬라임 2~3마리로 분열**한다 (풍선의 레이어 개념을 "분열" 메커니즘으로 재해석).
- 첨부된 리소스처럼 슬라임은 **재질(색상/속성) × 얼굴(성격/패턴)** 조합으로 무한에 가까운 종류를 만들 수 있어, Bloons의 "블루/레드/블랙/세라믹" 같은 속성 체계를 **훨씬 풍부한 비주얼로 확장**할 수 있는 것이 최대 강점이다.

---

## 3. 핵심 게임플레이 루프

```
웨이브 시작 → 슬라임들이 정해진 경로(Path)를 따라 이동
   → 플레이어가 배치한 유닛(타워)이 자동 공격
   → 슬라임 피격 시 넉백/찌그러짐 반응 → 체력 소진 시 "분열" or "소멸"
   → 경로 끝 도달 시 라이프 감소
   → 웨이브 클리어 → 골드/재화 획득
   → 골드로 신규 유닛 배치 / 기존 유닛 업그레이드
   → 다음 웨이브(난이도 상승, 새로운 슬라임 등장)
```

라이프가 0이 되면 게임오버, 전체 웨이브를 막아내면 스테이지 클리어.

---

## 3-1. 실패 조건

- **라이프 시스템**: 플레이어는 스테이지 시작 시 일정량의 라이프(생명력)를 보유한다
- 슬라임이 처치되지 않고 **경로 끝까지 도달**하면 라이프가 차감된다
- **라이프가 0이 되면 게임오버**
- 슬라임 종류별 차감량, 분열 상태에 따른 차감 규칙 등 세부 수치는 추후 밸런싱 단계에서 결정한다

## 4. 슬라임 몬스터 디자인 — 7종 베이스 활용안

업로드된 리소스는 **7가지 슬라임 베이스 형태**(뿔 있음/없음, 귀 모양, 꼬리 유무 등)와 **재질(색상) 팔레트**, **얼굴 텍스처**가 분리되어 있어, 이를 조합해 Bloons의 풍선 등급 체계처럼 설계할 수 있다.

| 슬라임 속성(재질 기반) | 참고 색상 | 특징 | Bloons 대응 개념 |
|---|---|---|---|
| 기본 슬라임 | 흰색/베이지 | 낮은 체력, 기본 속도 | 레드 블룬 |
| 스피드 슬라임 | 노랑/주황 뿔 | 이동속도 빠름 | 옐로우 블룬 |
| 탱크 슬라임 | 갈색/뿔 큰 형태 | 체력 매우 높음, 느림 | 세라믹 블룬 |
| 냉기 슬라임 | 하늘색, 별 무늬 | 아군 타워 슬로우 디버프 부여 | — (신규) |
| 화염 슬라임 | 빨강, 뿔 | 화염 데미지 면역/반사 | — (신규) |
| 그림자 슬라임 | 검정/보라 | 은신(일부 타워에 안 보임) | 카모 블룬 |
| 보스 슬라임 | 무지개/대형 | 초대형, 처치 시 다량 분열 | MOAB 계열 |

**분열 메커니즘 예시**: 탱크 슬라임(대) → 피격 누적 시 기본 슬라임(중) 2마리로 분열 → 각각 추가 피격 시 미니 슬라임(소) 2마리씩 분열 → 완전 소멸. 이 "젤리가 쪼개지는" 연출 자체가 슬라임 소재만의 차별화 포인트다.

**얼굴 표정 시스템 활용**: 첨부 이미지의 다양한 표정(눈물, X자 눈, 하트 눈 등)을 상태 표시로 활용한다 — 예) 슬로우 디버프 걸리면 눈이 빙글빙글, 체력 낮으면 눈물 표정 등 → 별도 UI 없이도 상태를 직관적으로 전달할 수 있다.

## 5. 타워(유닛) 시스템

Bloons처럼 **다양한 역할군 + 티어별 업그레이드 분기** 구조를 권장한다.

| 유닛 유형 | 역할 | 예시 컨셉 |
|---|---|---|
| 단일 타격형 | 빠른 연사, 단일 대상 | 슬라임 사냥꾼(활/총) |
| 스플래시형 | 광역 데미지 | 슬라임 폭탄병 |
| 슬로우/디버프형 | 이동속도 감소 | 얼음 마법사 |
| 관통/라인형 | 일직선 다수 관통 | 레이저/화염방사 유닛 |
| 특수 처리형 | 은신/특수속성 대응 | 그림자 탐지 유닛 |
| 궁극기형 | 쿨타임 기반 필드 스킬 | 전체 슬로우, 전체 데미지 |

각 유닛은 **2~3갈래 업그레이드 트리**(예: 공격력 라인 vs 유틸리티 라인)로 분기해 빌드 다양성을 확보한다.

## 6. 진행/메타 시스템

- **재화**: 인게임 골드(스테이지 내 소모) + 프리미엄 재화(스킨/영구 강화)
- **슬라임 도감**: 처치/발견한 슬라임 조합을 도감처럼 기록한다 → 수집 동기 부여
- **슬라임 스킨 뽑기(선택적 BM)**: 재질×얼굴 조합을 활용해 "레어 슬라임 스킨"을 유닛 코스메틱으로 판매할 수 있다 (직접적 P2W보다는 수집/꾸미기 요소로)
- **스테이지 진행**: 테마별 맵(숲/사막/빙하/화산) → 후반 맵일수록 해당 속성 슬라임이 대거 등장한다

## 7. 재미 포인트 (핵심 요약)

기획 시 이 부분에 가장 공을 들이는 것이 좋다. 우선순위 순으로 정리했다.

1. **말랑말랑 손맛 (Juice)** — 슬라임이 맞을 때마다 찌그러지고 튕기는 물리 반응, 분열 시 통통 튀며 갈라지는 연출. 소재 자체가 주는 촉각적 쾌감이 이 게임의 최대 차별점이다. 타격감에 사운드/이펙트 투자를 아끼지 않아야 한다.
2. **속성 상성 전략** — 색상=속성 체계를 명확히 해서 "이번 웨이브는 화염 슬라임이 많으니 냉기 유닛을 더 배치해야겠다" 같은 판단이 재밌게 작동하도록 설계한다.
3. **분열 체인 리액션** — 한 유닛의 광역 공격이 여러 슬라임을 동시에 쪼개고, 쪼개진 슬라임들이 다시 연쇄로 처리되는 콤보감 (핀볼처럼 슬라임이 튕기며 처리되는 그림이 나오면 이상적이다).
4. **수집욕 자극** — 무한에 가까운 슬라임 커스터마이징 조합을 "새로운 종류 발견" 경험으로 전환한다 (도감 완성 욕구).
5. **타워 빌드 전략성** — Bloons 특유의 "이 조합이면 이 웨이브를 막을 수 있을까?" 하는 최적화 재미를 그대로 계승한다.
6. **보스/특수 웨이브 서프라이즈** — 거대 보스 슬라임 등장 시 화면을 가득 채우는 압도감 + 처치 시 대량 분열하는 카타르시스.
7. **경쾌한 코미디 톤** — 슬라임 표정(X자 눈, 눈물, 하트눈 등)을 활용한 유머러스한 리액션으로 캐주얼 유저 진입장벽을 낮춘다.

## 8. 아트 스타일 방향

- 첨부 레퍼런스처럼 **파스텔톤 + 둥글둥글한 실루엣 + 단순한 이모지 얼굴**을 유지한다
- **재질(Material) 레이어 + 얼굴(Face) 텍스처 레이어 분리** 시스템을 그대로 개발 파이프라인에 적용하면, 아티스트가 베이스 메시 7종만 만들어도 색상×표정 조합으로 수십~수백 종의 슬라임을 저비용으로 양산할 수 있다 (리소스 효율 측면에서도 이미 최적화된 구조)
- 배경/맵도 슬라임과 톤을 맞춘 로우폴리+파스텔 스타일을 권장한다
