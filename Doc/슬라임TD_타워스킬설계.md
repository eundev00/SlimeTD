# 슬라임TD — 타워 스킬 설계

타워의 기본 공격, 레벨 성장, 스킬 구조와 전투 판정 규칙을 정의한다. 기존의 공용 스킬 풀(어떤 타워에도 꽂는 방식)은 폐기하고 **타워 귀속 스킬 + 공통 부품** 구조로 다시 설계했다.

- 레퍼런스: [타워 스킬 레퍼런스 조사](슬라임TD_타워스킬_레퍼런스조사.md)
- 타워 종류와 등급별 공격력: [타워 로스터](슬라임TD_타워로스터.md)
- 데이터 구조: [데이터 구조 설계](슬라임TD_데이터구조설계.md)
- 수치는 전부 변경될 수 있는 예시다

---

## 1. 용어

| 용어 | 의미 |
|---|---|
| **타워 레벨** | 로비에서 올리는 **영구 성장**. 타워 종류별로 쌓이며 합성과 무관하다. **최대 15** |
| **타워 강화** | 전투 중 성장. 전투가 끝나면 초기화된다. **후순위** |
| **기본 공격** | 타워가 공격속도마다 자동으로 하는 한 발 발사. 스킬이 아니다 |
| **스킬** | 타워에 귀속된 효과. 상시 적용되거나 조건이 맞을 때 자동 발동한다 |

비용과 재화 등 타워 레벨의 상세 수치는 메타 작업 단계에서 구체화한다.

## 2. 타워 구성

### 기본 공격

- **한 발 발사만 담당한다.** 관통, 다중 발사, 크리티컬 강화 등은 전부 스킬로 분리한다
- 기본 공격은 스킬이 아니다

### 레벨 성장

레벨이 오르면 **기본 공격력만** 오른다.

- 증가율은 **등급 단위로 일정**하다. 레벨당 기준공격력의 N%씩 오르고, 등급 시트에서 지정한다(현재 5%)
- 공격력 = `기준공격력 × (1 + 증가율 × (레벨 - 1))`. 예: 일반 100, 5% → Lv 15에서 170
- **공격속도는 레벨로 오르지 않는다.** 필요한 타워는 공격속도 강화 패시브 스킬을 만들어 특정 레벨에 해금해서 올린다 (운빨존많겜도 공격속도는 등급으로 고정이고 특정 레벨의 고정 업그레이드로만 오른다)

### 기본 치명타

모든 타워가 기본으로 가지며, 값은 타워 시트에서 타워마다 지정한다. 기본값은 아래와 같다.

| 항목 | 기본값 |
|---|---|
| 치명타 확률 | 10% |
| 치명타 보너스 | 100% |

### 스킬 목록

- 타워는 **기본 장착 스킬 + 레벨에 해금되는 스킬**을 가진다. 해금 레벨은 기본 1이다
- 스킬은 **타워에 귀속**된다. 스킬을 임의의 타워에 꽂거나 빼지 않는다
- 스킬이 쓰는 부품(치명타, 확률 판정, 쿨타임, 효과 종류)은 **공통**이다 — [3장](#3-스킬-구성-부품)
- 현재 타워마다 스킬 3개를 **5 / 10 / 15레벨**에 해금하고, 15레벨에 그 타워의 매력이 되는 스킬을 둔다 — [6장](#6-타워별-스킬)
- 같은 스킬의 강화 단계(예: 쌍발 사격 → 쌍발 사격 II)는 업그레이드 계열로 묶는다. 업그레이드가 해금되면 이전 단계는 꺼지고 가장 높은 단계 하나만 적용된다
- UI 슬롯은 **계열 하나당 하나**다. 잠긴 슬롯은 자물쇠, 다음 단계가 남은 슬롯은 화살표로 표시한다 (UI는 미구현)
- 등급별 스킬 개수 기준이나 상한은 두지 않는다. 패시브가 많은 타워도, 특수 스킬이 많은 타워도 있다. 이것은 타워 특성으로 설계한다
- 직업 귀속 스킬(석궁병의 관통, 레인저의 광역, 착한 슬라임의 감속 등)은 해당 타워만의 정체성이다

## 3. 스킬 구성 부품

스킬은 **시점 / 확률 / 쿨타임 / 대상 / 효과**를 조합해 정의한다. 시점, 확률, 쿨타임은 서로 독립이다.

| 부품 | 값 | 설명 |
|---|---|---|
| 시점 | 상시 / 공격 시 / 타격 시 / 처치 시 / N번째 공격 | 언제 적용되는가 |
| 확률 | 없음 또는 N% | 시점이 맞을 때 발동할 확률 |
| 쿨타임 | 없음 또는 N초 | 한 번 발동한 뒤 다시 발동하기까지의 대기. **공격속도와 독립이다** |
| 대상 | 기본 타겟 / 보스 우선 / 범위 내 전체 / 아군 전체 | 누구에게 적용되는가 |
| 효과 | 수치 변경 / 배율 공격 / 추가 피해 / 이감 / 버프 / 젤리 / 다중 발사 / 관통 | 무엇을 하는가 |

### 발동 원칙

- **자동 발동만 쓴다.** 플레이어가 조작하는 액티브 스킬은 도입하지 않는다 (세로 한 손 조작)
- 발동 조건은 **확률**과 **쿨타임**이고 함께 쓸 수 있다. 쿨타임은 발동했을 때부터 흐른다. 마나는 고려하지 않는다
- N번째 공격 발동은 기본 공격 횟수를 세므로 공격속도의 영향을 받는다
- 구현된 시점은 **상시**와 **공격 시**다. 타격 시, 처치 시, N번째 공격은 아직 없다

## 4. 전투 판정 규칙

### 공격과 판정 단위

| 항목 | 규칙 |
|---|---|
| 공격 1회 | 기본 공격 1번. 다중 발사가 터져도 1회로 센다 |
| N번째 공격 카운터 | **공격 횟수** 기준이며 발사한 화살 수가 아니다 |
| 발동 판정 | 공격 시 스킬의 확률과 쿨타임은 **공격 1회마다 한 번** 굴린다 |
| 판정 순서 | 스킬 발동 판정 → 데미지 스킬이 안 터졌으면 치명타 판정 |
| 스킬 발동 시 | 데미지 스킬(다중 발사, 배율 공격, 광역)이 터진 공격은 **치명타 판정을 하지 않는다**. 배율 공격은 그 배율로만 계산한다 |
| 젤리 | 데미지와 무관하므로 터져도 치명타 판정에 영향을 주지 않는다 |
| 데미지 확정 | 원거리는 발사 시점, 근접은 타격 프레임에 확정한다 |

다중 발사 예시 (궁수 쌍발 사격): 공격할 때 10% 확률로 터지면 추가 화살이 0.15초 뒤에 나간다. 그 공격은 치명타가 없으므로 두 발의 데미지가 같다.

관통은 한 화살의 판정 결과를 그 화살이 맞힌 슬라임이 모두 공유한다. 같은 슬라임을 다음 프레임에 다시 맞히지 않는다.

광역은 맞은 대상 중심 반경 안의 **다른** 슬라임에게 중심 대상과 **같은 데미지**를 준다. 화살은 첫 타격 때 한 번만 터진다.

죽는 연출 중인 슬라임은 화살이나 광역에 다시 맞지 않는다 (처치 보상 중복 방지).

### 치명타 계산

```
치명타 피해 = 현재 공격력 + 현재 공격력 × 치명타 보너스
```

- **현재 공격력**은 레벨 성장분과 공격력 버프를 반영한 값이다
- 치명타 스킬은 확률과 보너스에 각각 더한다
- 예: 현재 공격력 50, 보너스 100% → 치명타 100
- 예: 보너스 +20%(합계 120%) → 50 + 60 = 110
- 예: 공격력 버프 +10%(55) → 일반 55, 치명타(보너스 100%) 110

## 5. 버프 / 디버프

버프와 디버프는 별개 시스템이며 동시에 사용할 수 있다. 버프는 타워에, 디버프는 슬라임에 걸린다.

### 감속

- 퍼센트를 **곱연산**으로 쌓는다: 기본 속도 × (1 − a) × (1 − b) …
- 하한은 기본 속도의 **25%**다 (초안, `GameConfig.SlowMinSpeedRatio`)
- 같은 타워가 다시 맞히면 **지속 시간만 갱신**한다. 다른 타워는 같은 종류라도 중첩된다
- 보스는 감속 수치를 **절반만** 적용한다 (`GameConfig.BossSlowScale`)
- 기절은 감속과 따로 최우선으로 처리한다 (기절 스킬은 아직 없음)
- 시트의 감속은 퍼센트(`%`)로만 쓴다
- 등급별 수치 상한 (초안): 일반 최대 5%, 희귀 10~15%, 영웅 15~20%, 전설 장판 30~40%

**중첩 단위는 스킬이 아니라 타워 하나다.** 타격 단위로 쌓으면 타워 하나가 연타만으로 감속을 무한히 쌓아버린다. 같은 종류의 타워가 여러 마리 있어도 각각 다른 타워로 본다. 타워는 생길 때마다 게임 중 번호 `SpawnId`를 받고(합성으로 새로 생겨도 새 번호), 타격 정보에 그 번호를 실어 보낸다. 슬라임은 번호별로 감속을 한 줄씩 관리한다.

예: 착한 슬라임(15레벨, 5%) 5마리가 같은 적을 맞히면 일반 적은 0.95⁵ ≈ 0.77(약 23% 감속), 보스는 2.5%씩이라 0.975⁵ ≈ 0.88(약 12% 감속)이다.

### 증가 버프

```
최종 값 = (기본값 + 고정 증가) × (1 + 퍼센트 증가 합) × 별도 배율
```

- 퍼센트 증가는 **합연산**이다 (공격력 +3%와 +5%는 +8%)
- 치명타나 보스 특효 같은 별도 배율은 **곱연산**이다
- 공격력 업은 상한이 없다

### 상시 효과와 지속 효과의 공존

지속 버프는 대부분 특수 스킬이고, 같은 종류의 지속 버프끼리 겹치는 일은 거의 없다고 보고 설계한다. 실제로 나오는 조합은 상시 효과와 지속 효과의 공존이다. 상시분과 지속분은 따로 보관해야 지속 효과 종료 시 상시 효과가 같이 사라지지 않는다.

예: 공격력 +10%(상시)와 +10%(1초간)가 있으면 평소 +10%, 1초 동안 +20%이고 이후 +10%로 돌아온다. (지속 버프 스킬은 아직 없음)

## 6. 타워별 스킬

실제 데이터는 [Skills.csv](../Assets/Datas/Sheets/Skills.csv)가 원천이다. 스킬 ID는 `타워ID×100+순번`이다. 수치는 밸런싱 단계에서 바뀔 수 있다.

| 타워 | 5레벨 | 10레벨 | 15레벨 |
|---|---|---|---|
| 궁수 101 | 묵직한 화살: 공격력 +3% | 쌍발 사격: 공격 시 10% 확률로 화살 2발 | 쌍발 사격 II: 20% 확률로 2발 (10레벨 대체) |
| 일병 103 | 재빠른 칼놀림: 공격속도 +5% | 급소 노리기: 치명타 확률 +5%p | 분쇄 일격: 공격 시 10% 확률로 공격력의 300% |
| 나무꾼 104 | 단단한 도끼날: 공격력 +5% | 벌목 수익: 공격 시 10% 확률로 젤리 5 | 벌목 수익 II: 10% 확률로 젤리 10 (10레벨 대체) |
| 착한 슬라임 105 | 신나는 던지기: 공격속도 +3% | 끈적 슬라임: 맞은 적 이동속도 −3%, 1초 | 끈적 슬라임 II: −5%, 1초 (10레벨 대체) |

| 기사 203 | 단련 I: 공격력 +5% | 단련 II: 공격력 +10% (5레벨 대체) | 단련 III: 공격력 +20% (10레벨 대체) |

스킬 아이콘은 `Assets/Art/UI/SkillIcon/SkillIcon_{스킬ID}.png`(128x128)이고 스킬 아이콘 아틀라스로 로드한다.

### 아직 쓰지 않은 후보

초기에 나열했던 아이디어 중 아직 어느 타워에도 들어가지 않은 것이다.

- 보스에게 추가 피해, 보스 우선 공격
- 타격 시 아군 공격력 증가 (지속 버프)
- 처치 시 젤리 (현재 젤리는 공격 시 확률 방식)
- 범위 내 모든 슬라임 공격, N번째 공격마다 발동

## 7. 미결 항목

- 감속 하한(25%)과 등급별 감속 상한의 확정
- 기절 효과와 기절 스킬
- 타격 시 / 처치 시 / N번째 공격 시점의 구현
- 스킬 슬롯 UI (계열당 1슬롯, 자물쇠, 화살표, 툴팁)
- 광역 연출 (범위가 화면에 보이지 않음)
- 일병, 레인저, 석궁병은 업그레이드 계열이 없어 슬롯이 3개가 된다. UI의 2슬롯 기준과 맞출지 결정
- 방어력 도입 여부. 도입하면 방감 스킬이 의미를 가진다 (공식 후보: 단순 차감 / 비율 감소 / 퍼센트 방어)
- 타워 레벨의 성장 수치, 비용과 재화: 메타 작업 단계
- 타워 강화(전투 중 성장): 후순위
- 영웅 / 전설 타워의 스킬 (타워 미정)

### 도입하지 않기로 한 것

- 마나 기반 발동
- 플레이어가 조작하는 액티브 스킬
- 슬라임 속성 상성 (현재 고려하지 않음)
