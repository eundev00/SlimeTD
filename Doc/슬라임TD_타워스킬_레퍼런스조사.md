# 슬라임TD — 타워 스킬 레퍼런스 조사

타워 스킬 설계를 위해 **Bloons TD 6 / 협동 타워 디펜스(협타디) / 운빨존많겜** 세 게임의 타워(유닛) 특성과 스킬 구조를 조사했다.

- 조사일: 2026-10-01
- 수치는 커뮤니티 위키·공략 기준이며 게임 패치로 바뀔 수 있다. 설계 참고용으로만 쓴다
- 협타디는 공개 자료가 적어 **마신급 유닛의 역할 요약 위주**다. 하위 등급 유닛별 스킬은 확인하지 못했다

## 1. Bloons TD 6

### 1-1. 시스템

- 타워는 **Primary / Military / Magic / Support** 4계열
- 업그레이드는 **3갈래(Path) × 5단계(Tier)**
  - 한 타워는 최대 2갈래만 찍을 수 있다
  - 3단계 이상은 1갈래만 가능하다 (예: 5-2-0, 0-2-5)
  - 같은 갈래의 5단계는 필드에 1개만 둘 수 있다
- **액티브 능력**은 보통 **중간 갈래 4단계**에서 열리고, 5단계에서 강화된다
- **파라곤**: 한 타워 종류의 5단계 3개가 모두 필드에 있을 때 합쳐서 만드는 6단계
- **히어로**: 맵당 1명, 라운드 진행에 따라 자동으로 1~20레벨 성장

### 1-2. 타워별 업그레이드 갈래 (3~5단계 요약)

`[A]` = 액티브 능력, `[P]` = 자동 발동 능력

### 1-3. BTD6 스킬 설계 패턴

| 패턴 | 예시 | 슬라임TD 적용 가능성 |
|---|---|---|
| **한 타워, 여러 역할 갈래** | 다트 몽키: 관통 / 연사+버프 / 원거리 크리 | 합성 루트를 갈래로 나누는 대신, 같은 계열 안에서 다른 Tier 2를 랜덤으로 주는 방식으로 변형 가능 |
| **적 속성 대응 업그레이드** | 납·위장·MOAB·요새화 대응 | 슬라임 속성(냉기/화염/그림자) 도입 시 "이 속성만 잡는 타워" 설계 근거 |
| **상태이상 → 추가 피해 연계** | 아이스 취약화, 공룡의 기절 대상 추가 피해 | 둔화/기절 타워와 딜러 타워 간 시너지 |
| **주변 타워 버프** | 연금술사, 빌리지, 드루이드 | 그리드 배치에 인접 버프를 주면 위치 전략이 생긴다 |
| **희생/흡수** | 태양 신전, 빌리지 농장 흡수 | 합성 외의 소모 수단 |
| **적을 되돌리기** | 넉백, 하강풍, 좀비 부활 | "쪼개진 슬라임이 튕겨나가는" 손맛과 잘 맞음 |
| **라이프 손실 시 발동** | 폭탄 폭풍, 엘리트 디펜더 | 위기 역전 연출 |
| **경제형** | 농장, 상선, 덫 | 랜덤 소환 구조에서는 골드 타워가 소환 기회를 늘려준다 |

### 1-4. 적 속성 체계 (상성 참고)

BTD6의 상성은 "타워 속성 vs 풍선 속성"으로 작동한다. 슬라임 속성 설계 시 참고.

| 풍선 속성 | 효과 | 대응 수단 |
|---|---|---|
| 납(Lead) | 날카로운 공격 면역 | 폭발·화염·레이저 |
| 검정 / 흰색 / 얼룩 | 폭발 면역 / 빙결 면역 / 둘 다 | 다른 속성 공격 |
| 보라 | 마법·화염·플라즈마 면역 | 물리 공격 |
| 위장(Camo) | 탐지 타워만 공격 가능 | 탐지 업그레이드, 빌리지 |
| 재생(Regrow) | 체력 회복 | 재생 제거 |
| 요새화(Fortified) | 체력 증가 | 추가 피해 업그레이드 |
| MOAB 계열 | 초대형, 분열하며 하위 풍선 방출 | MOAB 특화 타워 |

**MOAB → 하위 풍선 분열 구조가 슬라임TD의 분열 메커니즘과 거의 같다.** 특화 타워(분열 전 본체만 때리는 타워 / 분열 후 잔챙이 청소 타워)를 나누는 근거가 된다.

## 2. 협타디 (협동 타워 디펜스)

### 2-1. 시스템

- 2인 협동. 각자 나뉜 전장을 지키면서 중앙의 마왕성을 함께 방어한다
- 플레이어 유닛이 **마물**(슬라임·고블린·기사·주술사·용·기계 등)이고, 적이 **인간 군대**다
- **소환**: 골드로 일반 등급 마물을 랜덤 소환
- **합성**: 같은 종류·같은 등급 **2개** → 상위 등급 1개
- **등급**: 일반 → 희귀 → 영웅 → 전설 → **마신** (마신을 강화한 **초마신**은 별도 레벨·유물·해방 단계를 가짐)
  - 영웅부터 고유 능력이 생긴다
  - 전설은 주로 마신 제작 재료다
- **전투 중 강화**: 일반/희귀/영웅 등 **등급별로 공격력을 강화**하면 그 등급 마물 전체에 적용된다
- **마석**: 광산 슬라임을 고용해 전투 중 주기적으로 획득하는 보조 재화
- 목표: 최대 110웨이브 생존

### 2-2. 역할 분류

| 역할 | 기능 |
|---|---|
| 공격형 | 직접 피해 |
| 광역 공격형 | 범위 내 다수 동시 공격 |
| 보스 공격형 | 단일 대상, **최대 체력 비례 피해** |
| 군중 제어형 | 기절, 빙결, 둔화, 끌어당김 |
| 지원형 | 아군 능력 강화 |
| 약화형 | 적 방어력·이동 속도 감소 |
| 자원형 | 골드·마석 생산 |

### 2-3. 마신 / 주요 유닛

| 유닛 | 역할 | 특성 / 스킬 |
|---|---|---|
| **검귀** | 광역 딜러 | 높은 지속 피해, **최대 체력 비례 광역 피해** |
| **빙결기사** | 군중 제어 | **영구 빙판**을 깔아 이동 속도 감소, 기절 |
| **클라라** | 만능 딜러 | 높은 공속·공격력, **필드 전체 공격** |
| **고대 청룡** | 지원 | 모든 아군 공격력 증가 |
| **부두술사** | 지원 | 필드 모든 아군 공격 속도 증가 |
| **마스터 캣** | 단일 딜러 | 강력한 단일 대상 스킬 |
| **빅핸드** | 광역 제어 | 대지진 스킬(광역 피해 + 기절) |
| **미믹** | 자원/랜덤 | 상자를 소환해 **랜덤 마신 또는 자원** 지급 |
| **깜짝쥐** | 딜러 | 공속 증가, 초대형 폭탄 공격 |
| 오멘, 캐논, 에그비, 아수라, 아이비 | — | 상세 스킬 미확인 |

#### 기타 유닛

| 유닛 | 특성 |
|---|---|
| 고블린 폭주족 | **치명타 시 골드 획득** |
| 코인맨 | **보유 골드 비례 공격력** |
| 파오리 | 파를 강화해 대파 광역 공격 (성장형) |
| 헬리콥터 머신 | **자유 이동 가능**, 필드에 1개만 존재 |
| 우주병사 | **계급이 오르면서** 치명타·공속 증가 (전투 중 성장) |
| 팬텀 슬라임 | 영혼을 소환해 추가 딜 |

### 2-4. 협타디 스킬 설계 패턴

- **2개 합성 + 5등급** 구조로 슬라임TD와 가장 가깝다
- 등급이 오를수록 "능치 상승 → 고유 능력 → 강력한 기술"로 스킬 복잡도가 단계적으로 늘어난다
- 최상위(마신)는 **"필드 전체 버프" / "필드 전체 공격" / "최대 체력 비례"**처럼 스케일이 큰 효과를 가진다
- 경제형(골드 획득, 골드 비례 공격력)과 랜덤형(미믹)이 랜덤 소환 구조의 재미를 보강한다
- 전투 중 성장(우주병사 계급, 파오리 강화)으로 같은 유닛이라도 오래 둘수록 강해진다

## 3. 운빨존많겜 (Lucky Defense)

### 3-1. 시스템

- **소환**: 골드로 랜덤 소환
- **합성**: 같은 유닛 **3개** → 상위 등급 **랜덤 유닛** 1개
- **등급**: 일반 → 희귀 → 영웅 → 전설 → **신화** (+ 불멸)
- **도박**: 행운석으로 확률 기반 유닛 획득
- **신화 조합**: **지정된 재료 유닛 조합**으로만 만든다 (예: 전설 1 + 영웅 1 + 일반 1)
- **피해 타입**: 물리(방어력 영향) / 마법(방어력 무시)
- **궁극기**: **전설부터** 생긴다
  - 물리 딜러는 쿨타임 방식
  - 마법 딜러는 마나 방식. 마나는 자연 회복 + 공격 시 획득
- **영구 성장**: 로비에서 유닛 레벨업. 특정 레벨(예: 6, 12)에 스킬이 해금되거나 강화된다
- **보물**: 신화 유닛 10레벨에 해금되는 장비 (일반 보물 / 전용 보물)
- 보스는 10웨이브마다 등장

### 3-2. 등급별 유닛

약어: 이감 = 이동 속도 감소, 방감 = 방어력 감소, 공증 = 공격력 증가

| 궁수 | 6레벨: **더블샷** 해금 |
| 투척병 | 범위 공격 |
| 야만인 | 특성 없음 (재료용) |

| 성기사 | 범위 내 적 공격 |
| 레인저 | 특성 없음 |

#### 영웅

#### 신화 (주요)

|---|---|---|
| **랜슬롯** | 최상위 딜러 | 공증 패시브, 강화 시 **최대 체력 비례 피해** |

| **시공 아토** (불멸) | 지원 | 방감 시너지 |

### 3-3. 등급별 기본 공격력

괄호는 레벨당 증가치(1→15레벨).

#### 일반

| 유닛 | 공격력 | 공격속도 | 타입 |
|---|---|---|---|
| 산적 | 100 (+5) | 1 | 근거리 |
| 야만인 | 100 (+5) | 0.5 | 근거리 |
| 물의 정령 | 60 (+3) | 1 | 원거리 |
| 투척병 | 50 (+2.5) | 1 | 원거리 |
| 궁수 | 50 (+2.5) | 1 | 원거리 |

#### 희귀

| 유닛 | 공격력 | 공격속도 | 타입 |
|---|---|---|---|
| 악마병사 | 150 (+7.5) | 2 | 근거리 |
| 성기사 | 150 (+7.5) | 2 | 근거리 |
| 레인저 | 150 (+7.5) | 2 | 원거리 |
| 샌드맨 | 120 (+6) | 2 | 원거리 |
| 충격로봇 | 120 (+6) | 2 | 원거리 |

#### 영웅

나무위키에 개별 수치가 기재돼 있지 않다. 다만 임프(1,000) 항목 서술에서 "일부 영웅 등급은 강화 안 해도 1000을 넘긴다"고 나오므로, 기본 공격력이 1,000 전후 구간이다.

#### 전설

| 유닛 | 공격력 | 공격속도 | 타입 |
|---|---|---|---|
| 호랑이사부 | 6,000 (+300) | 2 | 근거리 |
| 보안관 | 5,000 (+250) | 2 | 원거리 |
| 폭풍거인 | 3,000 (+150) | 2 | 원거리 |
| 워머신 | 3,000 (+150) | 2 | 근거리 |

#### 신화

개체마다 편차가 크다. 참고 사례로 초나가 20,200 (+1,000), 공격속도 1.3이다.

#### 특수: 임프

1,000 (+50), 공격속도 1. 일반 등급으로 분류되지만 소환으로는 안 나오고 신화 영웅 마마의 궁극기 '사령술'로만 생성된다. 1레벨 임프의 공격력이 15레벨 희귀 등급보다 높다.

#### 등급 간 배율

1→2→3 순서로 보면 60 → 150 → (약 1,000) → 5,000 선이다. 희귀는 일반의 1.5~2.5배 수준으로 완만하고, 영웅에서 약 7배, 전설에서 다시 5배 전후로 뛴다. 후반 등급일수록 배율이 커지는 구조다.

공격속도는 일반이 1(야만인만 0.5), 희귀·전설이 2로 고정이다. 즉 희귀 단계에서 공격력 1.5배와 공격속도 2배가 동시에 적용돼 실 DPS는 3배 차이가 난다.

#### 레벨 성장

레벨당 증가치는 전부 기본 공격력의 5%다. 15레벨이면 기본값의 1.7배.

그 위에 고정 업그레이드가 붙는다. Lv.3 공격력 +10%, Lv.9 공격속도 +10%, Lv.15 공격력·공격속도 각 +10%. Lv.6과 Lv.12는 영웅마다 고유 업그레이드다(예: 늑대전사는 Lv.6에 물어뜯기 3초 기절 추가, Lv.12에 할퀴기 횟수 +1).

#### 전투 중 강화

인게임에서 코인(일반~영웅) 또는 행운석(전설~신화)을 소모해 등급별 공격력을 올린다. 업그레이드 1회당 기본 공격력의 50%씩 가산된다. 기본 100이면 150 → 200 → 250 → 300 순으로 선형 증가한다.

### 3-4. 운빨존많겜 스킬 설계 패턴

- **등급별 스킬 슬롯이 명확하다**: 하위 등급은 패시브 1개, 전설부터 궁극기가 붙는다
- **디버프 수치가 누적**된다 (이감/방감을 여러 유닛이 쌓음) → 역할 분담 유닛이 필요하다
- **"확률 발동" 스킬이 많다** — 랜덤 소환 게임의 도박감과 잘 맞는다
- **위험 부담이 있는 진화**(개구리 왕자: 성공 시 강화, 실패 시 소멸)가 긴장감을 만든다
- **처치 누적 성장**(블롭), **같은 대상 지속 공격 누적**(지지) 같은 "오래 둘수록 강해지는" 스킬
- 신화는 **지정 재료 조합**이라, 하위 유닛이 약해도 "재료"로서 가치가 생긴다

## 4. 슬라임TD 적용 시사점

### 4-1. 구조 비교

확정된 방향: **일반 → 희귀 → 영웅 → 전설**, 등급당 3~5종, 같은 타워 **2개 합성 → 다음 등급 무작위**, 계열 없음. 소환·합성은 **협타디(2개 합성)**와 같고, 스킬 단계 구성은 **운빨존많겜(등급별 스킬 슬롯)**을 참고하기 좋다.

| 등급 | 참고 구조 | 스킬 슬롯 제안 |
|---|---|---|
| 일반 | 운빨 일반 / 협타디 일반 | 기본 공격만 (현재: 단타/단일 대상) |
| 희귀 | 운빨 희귀~영웅 / 협타디 영웅 | **특수 메커니즘 패시브 1개** (현재 레인저 버스트, 기사 크리) |
| 영웅 | 운빨 전설 | 패시브 + **자동 발동 스킬**(쿨타임 또는 확률) |
| 전설 | 운빨 신화 / 협타디 마신 | **필드 전체급 효과** 또는 강력한 궁극기 |

### 4-2. 등급별 타워 후보 아이디어

계열이 없으므로 등급마다 역할(딜러/광역/제어/지원/경제)이 고르게 섞이도록 후보를 잡는다. 합성 결과가 무작위라 한 등급 안에 역할이 치우치면 운에 따라 빌드가 무너진다.

| 등급 | 역할 | 레퍼런스 | 아이디어 |
|---|---|---|---|
| 희귀 | 관통 딜러 | BTD6 석궁/스나이퍼 | 관통 수 증가, 관통할수록 피해 증가 |
| 희귀 | 제어 | 운빨 악마병사·충격로봇, BTD6 폭탄 1갈래 | 내려찍기 **기절** + 방감 |
| 희귀 | 경제 | 협타디 고블린 폭주족, 운빨 산적 | 처치 시 확률로 골드 |
| 영웅 | 광역 딜러 | BTD6 다트 3연발·택 슈터 | 부채꼴 다중 사격 |
| 영웅 | 넉백 | BTD6 하강풍·닌자, 운빨 캡틴 로카 | 크리 시 넉백, 슬라임이 튕겨나가는 손맛 |
| 영웅 | 지원 | 운빨 독수리장군·호랑이사부 | 주변 타워 공속 버프 |
| 전설 | 보스 딜러 | 협타디 검귀, 운빨 랜슬롯 | **최대 체력 비례 피해** |
| 전설 | 광역 제어 | 협타디 빙결기사, BTD6 아이스 | 경로에 영구 빙판(이감) |
| 전설 | 전역 버프 | 협타디 고대 청룡·부두술사 | 필드 전체 공격력/공속 증가 |

### 4-3. 슬라임 소재와 잘 맞는 메커니즘

| 메커니즘 | 레퍼런스 | 슬라임TD 연결 |
|---|---|---|
| **분열 전 본체 특화 / 분열 후 청소 특화** | BTD6 MOAB 특화 vs 광역 타워 | 분열 메커니즘 도입 시 타워 역할 분리의 핵심 축 |
| **넉백 / 뒤로 밀기** | BTD6 하강풍·닌자, 운빨 캡틴 로카 | 슬라임이 물컹하게 튕겨나가는 **손맛 연출**과 직결 |
| **영구 장판(빙판·가시)** | 협타디 빙결기사, BTD6 스파이크 공장 | 경로 셀(`GridCellState.Path`)에 장판 효과를 까는 형태 |
| **취약화 / 방감** | BTD6 아이스 취약화, 운빨 방감 | 얼굴 표정 시스템으로 디버프 상태 표시(기획서 4장) |
| **처치 시 성장** | 운빨 블롭, 협타디 우주병사 | 분열로 처치 수가 늘어나는 구조와 시너지 |
| **인접 버프** | BTD6 연금술사·빌리지 | 그리드 배치 전략성 강화, 재배치 동기 부여 |
| **처치 시 골드** | 협타디 고블린 폭주족, 운빨 산적 | 랜덤 소환 기회를 늘리는 경제형 타워 |
| **위험 부담 진화** | 운빨 개구리 왕자 | 캐주얼 도박감. 과하면 스트레스라 1~2종만 |

### 4-4. 결정이 필요한 항목

- 스킬 발동 방식: 쿨타임 / 확률 / 마나 중 무엇을 기본으로 할지 (운빨은 물리=쿨타임, 마법=마나로 나눔)
- 액티브(플레이어 조작) 스킬 여부: BTD6식 버튼 발동 vs 협타디·운빨식 자동 발동. 세로 한 손 조작이면 **자동 발동이 기본**, 액티브는 4등급 한정 검토
- 버프/디버프 중첩 규칙: 같은 종류 중첩 허용 여부, 상한
- 전투 중 등급별 강화 도입 여부 (협타디·운빨 공통 요소)
- 슬라임 속성 상성 도입 시기: 속성이 없으면 "특정 적 대응 타워"의 가치가 약해진다
