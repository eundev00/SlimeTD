# 슬라임TD — 메타 재화와 결과 보상 밸런스

2026-11-24 확정. 서버와 데이터 시트에는 반영했고, 클라이언트 화면은 작업 중이다.

## 1. 메타 재화 (영구)

| 재화 | 역할 | 획득 | 사용처 |
|---|---|---|---|
| 코인 | 소프트 재화 | 스테이지 결과 보상, 만렙 카드 환급 | 헌터 레벨업, 상점 |
| 팩 티켓 | 뽑기 재화 | 스테이지 결과 보상 | 헌터 카드팩 개봉 |
| 에너지 | 입장 재화 | 시간 회복, 광고, 다이아 충전 | 스테이지 입장 |
| 다이아 | 프리미엄 재화 | 결제, 업적·이벤트, 스테이지 최초 클리어 | 팩 티켓·에너지 충전, 전설 헌터 해금, 스킨, 패키지 |

- 헌터 카드팩은 코인이 아니라 팩 티켓으로 연다. 카드 1장 = 팩 티켓 10장 (1장 팩 10장, 10장 팩 100장)
- 다이아는 수집·꾸미기·편의 위주로 쓰고, 성장에 직접 쓰는 건 최소화한다
- 경험치와 유저 레벨은 넣지 않는다. 레벨업 보상이 없어 의미가 없어서 뺐다 (11-24)
- 인게임 재화(골드, 젤리)는 [게임 기획서 6-1](슬라임TD_게임기획서.md#6-1-재화-구성) 참고

## 2. 전제

| 항목 | 값 |
|---|---|
| 기준 플레이량 | 하루 15판 (일주일 105판), **모든 판 클리어(50웨이브) 기준** |
| 뽑기 등급 확률 | 일반 70% / 희귀 22% / 영웅 7%. 전설은 뽑기에서 나오지 않는다 |
| 헌터 수 | 일반 4 / 희귀 2 (현재), 영웅 3 (가정) |
| 성장 목표 | 일반 헌터 1명 1→15레벨 약 2주 |

## 3. 헌터 해금과 뽑기

- 일반·희귀·영웅 헌터는 처음부터 열려 있다. 모노리스도 연다 (해금 확인용으로 잠가 두었던 것)
- 전설 헌터는 다이아 구매 또는 이벤트 지급으로만 연다
- 헌터 카드 뽑기에서는 보유(해금)한 헌터 카드만 나온다. 잠긴 카드 규칙과 천장은 없다
- 소환과 합성 결과는 해금된 헌터에서만 나온다

## 4. 에너지

| 항목 | 값 |
|---|---|
| 1판 소모 | 5 |
| 최대치 | 30 (시간 회복은 30까지. 보상·이벤트로는 30을 넘겨 가질 수 있다) |
| 회복 | 10분당 1 (최대치까지 5시간) |
| 자연 회복 하루 최대 | 약 28판 |

## 5. 판당 결과 보상

| 재화 | 클리어 | 실패 |
|---|---|---|
| 팩 티켓 | 390장 (39장 뽑기) | 클리어 보상 × 도달 구간 비율 × 50% |
| 코인 | 700 | 〃 |

- 도달 구간 비율 = 통과한 구간 수 ÷ 5 (10웨이브 = 1구간)
- 예) 30웨이브 실패 → 팩 티켓 117장, 코인 210
- 첫 구간을 못 넘기면 보상이 없다
- 스테이지 최초 클리어: 다이아 10 (한 번만)

## 7. 만렙 카드 환급

15레벨 헌터의 카드는 장당 10코인으로 자동 환급한다. 판당 카드가 39장이라 만렙 헌터가 늘수록 코인 수입에서 차지하는 몫이 커진다 (일반 1명 만렙이면 주 약 1만 코인). 우선 유지하고 흐름을 보고 조정한다.

## 8. 예상 성장 속도

주당 뽑기 카드 4,095장 기준 (판당 39장 × 105판).

| 등급 | 헌터 1명이 주에 받는 카드 | 카드 만렙 |
|---|---|---|
| 일반 | 약 717장 | 약 2주 |
| 희귀 | 약 450장 | 약 2.4주 |
| 영웅 | 약 96장 | 약 9주 |

코인은 주당 약 7.4만(판당 700)이다. 일반 4명을 만렙 하는 데 17.8만이 들어 약 2.4주가 걸리므로, 초반에는 카드보다 코인이 성장 속도를 정한다.

레퍼런스(클래시 로얄, 러시 로얄)는 카드 하나를 만렙 하는 데 수개월이 걸린다. 우리는 헌터 수가 적고 최대 레벨이 15라 더 빠르게 잡았다.

## 9. 클라이언트 작업

서버(프로토콜·로직·데이터 시트)는 반영을 마쳤다. 아이템 ID: 팩 티켓 1000006, 에너지 1000007.

| 작업 | 상태 |
|---|---|
| 프로토콜 복사, 천장·잠긴 카드 제거, 시트 → SO (레벨업 비용, 팩, 모노리스 해금, 아이템) | 완료 |
| 팩 티켓·에너지를 `IAccountService`에 추가, 로비 상단 에너지 칩, 서버 시각 기준 회복 남은 시간 | 완료 |
| 로비 플레이·결과 한번더 버튼에 에너지 소모 배지 (`GameConfig._energyCostPerBattle`, 표시용) | 완료 |
| 에너지 부족: 버튼은 막지 않고, 누르면 광고·다이아 충전 팝업 (`NOT_ENOUGH_ENERGY` 포함) | 팝업 예정 (지금은 로그) |
| 결과 한번더도 서버에 전투 시작을 받은 뒤 씬을 다시 연다 | 완료 |
| 결과 팝업 보상 칸에 팩 티켓·최초 클리어 다이아 아이콘 | 완료 |
| 헌터 뽑기 가격을 팩 티켓으로, 팝업 안에 보유 팩 티켓 칩 (`CurrencyPackTicket`) | 완료 |
| 카드가 필요 없는 레벨업(전설)에서 카드 게이지 숨기기 | 완료 |
| 서버 연결 확인 | 예정 |

- 재화 표시 위치: 로비 상단은 에너지, 코인, 다이아만. 팩 티켓은 헌터 카드팩 구매 팝업 안에 표시한다
- 새 재화 아이콘은 `Assets/Art/UI/Common`에 있다: `IconEnergy`(Layer Lab `Economy_Energy_01_Yellow` 사본), `IconPackTicket`(`UI_Shop_Ticket_01_Gold` 사본). `IconExp`(EXP 아이콘)는 경험치를 뺐지만 남겨 둔다
- 로비 프로필의 레벨 배지와 게이지는 연결할 값이 없지만 우선 그대로 둔다

## 10. 미확정

- 에너지를 쓰는 시점(입장 때 또는 결과 때), 광고·다이아 충전량
- 후반 코인 잉여를 흡수할 소비처 (상점, 펫, 유물 등)
- 스테이지별 보상 배율 (지금은 단일 기준)
- 전설 헌터의 다이아 가격과 전설 등급 구성
- 신화 등급 레벨업 재료, 펫·유물 재화, 뽑기 재화 통합 여부
- 영웅 헌터 수가 확정되면 만렙 기간을 다시 계산
- 시뮬레이션 시트로 주차별 재화 흐름 검증
